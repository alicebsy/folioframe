# Folioframe MVP — SPEC

## 1. 목표

취업 준비생이 로그인한 뒤 자신의 프로젝트를 **담당 역할 → 문제 상황 → 해결 과정 → 구체적 성과** 순서로 직접 작성하고, 고유 주소로 공개한다.

## 2. 고정 기술 스택

- Frontend·Backend: Next.js
- Database: PostgreSQL
- Deployment: Vercel

다른 프레임워크나 배포 플랫폼으로 변경하지 않는다.

## 3. MVP 범위

1. 이메일·비밀번호 회원가입, 로그인, 로그아웃
2. 로그인한 사용자의 프로젝트 목록 조회
3. 프로젝트 직접 작성 및 텍스트 링크 등록
4. 프로젝트 공개 전환
5. 고유 주소 발행
6. 발행 성공·실패 안내

### 제외

- GitHub 및 다른 외부 서비스 연동
- 이미지·PDF 업로드
- AI 콘텐츠 생성
- 다중 템플릿과 자유 배치 편집
- 댓글, 협업, 방문자 분석
- 채용 공고·지원 현황·지원자 평가

## 4. 주요 화면

### 로그인

```text
+--------------------------------------------------+
| Folioframe                                       |
| 이메일    [_______________________________]      |
| 비밀번호  [_______________________________]      |
|                 [ 로그인 ]                       |
| 처음인가요? [간단 회원가입]                      |
+--------------------------------------------------+
```

### 대시보드

```text
+------------------------------------------------------------------+
| Folioframe                       [공개 페이지] [발행하기] [로그아웃] |
+------------------------------------------------------------------+
| 프로필: 이름 · 희망 직무 · 한 줄 소개 · 공개 주소                |
|                                                    [프로필 편집] |
+------------------------------------------------------------------+
| 내 프로젝트                                      [+ 프로젝트 작성] |
| 프로젝트 A                         작성 완료 · 공개    [수정]     |
| 프로젝트 B                         작성 중 · 비공개    [수정]     |
+------------------------------------------------------------------+
```

### 프로젝트 작성

- 프로젝트명
- 프로젝트 개요
- 담당 역할
- 문제 상황
- 해결 과정
- 구체적 성과
- 텍스트 링크: 이름과 `http://` 또는 `https://` URL, 최대 5개

프로젝트명만 입력해도 작성 중 상태로 저장할 수 있다. 모든 항목을 작성한 프로젝트만 공개할 수 있다.

### 발행 성공

- 공개 URL 표시
- 주소 복사
- 공개 페이지 열기
- 대시보드로 돌아가기

### 발행 실패

- 프로필 필수값 미입력
- 공개 프로젝트 없음
- 공개 프로젝트 필수값 미입력
- 공개 주소 중복
- 서버 또는 네트워크 오류

실패 원인과 수정 또는 재시도 버튼을 표시한다.

## 5. 핵심 데이터

### users

| 컬럼 | 설명 |
|---|---|
| id | 사용자 UUID |
| email | 로그인 이메일, UNIQUE |
| password_hash | 해시된 비밀번호 |
| created_at | 가입 시각 |

### sessions

| 컬럼 | 설명 |
|---|---|
| token_hash | 세션 토큰 해시 |
| user_id | 사용자 ID |
| expires_at | 만료 시각 |

### portfolios

| 컬럼 | 설명 |
|---|---|
| id | 포트폴리오 UUID |
| owner_id | 소유 사용자 ID, UNIQUE |
| name | 이름 |
| job_title | 희망 직무 |
| bio | 한 줄 소개 |
| contact_email | 공개 이메일 |
| slug | 공개 주소, UNIQUE |
| is_published | 발행 여부 |
| published_at | 발행 시각 |

### projects

| 컬럼 | 설명 |
|---|---|
| id | 프로젝트 UUID |
| portfolio_id | 소속 포트폴리오 ID |
| title | 프로젝트명 |
| summary | 개요 |
| role | 담당 역할 |
| problem | 문제 상황 |
| troubleshooting | 해결 과정 |
| result | 구체적 성과 |
| is_public | 공개 여부 |
| display_order | 노출 순서 |

### project_links

| 컬럼 | 설명 |
|---|---|
| id | 링크 UUID |
| project_id | 프로젝트 ID |
| label | 링크 이름 |
| url | 링크 URL |
| display_order | 노출 순서 |

## 6. API

| Method | 경로 | 설명 |
|---|---|---|
| POST | `/api/auth/register` | 회원가입 |
| POST | `/api/auth/login` | 로그인 |
| POST | `/api/auth/logout` | 로그아웃 |
| GET | `/api/portfolio` | 내 프로필·프로젝트 조회 |
| POST | `/api/portfolio/save` | 프로필 저장 |
| POST | `/api/portfolio/publish` | 포트폴리오 발행 |
| GET | `/api/projects` | 내 프로젝트 목록 |
| POST | `/api/projects` | 프로젝트 추가 |
| POST | `/api/projects/:id/update` | 프로젝트 수정 |
| POST | `/api/projects/:id/visibility` | 공개 상태 변경 |
| GET | `/api/public/:slug` | 공개 포트폴리오 조회 |

## 7. 보안 규칙

- 서버 세션의 `user_id`로 프로젝트 소유권을 확인한다.
- 클라이언트가 보낸 사용자 ID를 신뢰하지 않는다.
- 비밀번호는 bcrypt 해시로만 저장한다.
- 세션은 `HttpOnly`, `Secure`, `SameSite=Lax` 쿠키를 사용한다.
- `DATABASE_URL`, `SESSION_SECRET`은 Vercel 서버 환경변수에만 저장한다.

## 8. 완료 조건

- 회원가입, 로그인, 로그아웃이 가능하다.
- 로그인한 사용자는 자기 프로젝트만 조회·수정할 수 있다.
- 프로젝트와 텍스트 링크를 저장할 수 있다.
- 미완성 프로젝트는 공개할 수 없다.
- 공개 프로젝트가 1개 이상이면 포트폴리오를 발행할 수 있다.
- 성공 시 고유 URL을 복사하고 열 수 있다.
- 실패 시 원인과 재시도 방법이 표시된다.
- 공개 URL은 로그인 없이 조회할 수 있다.
- 새로고침 후에도 PostgreSQL 데이터가 유지된다.
