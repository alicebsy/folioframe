Folioframe

프로젝트 경험을 담당 역할 → 문제 상황 → 해결 과정 → 구체적인 성과 순서로 정리하고, 하나의 웹 포트폴리오로 발행하는 서비스입니다.

첫 번째 MVP에서 구현한 기능

  • 이메일·비밀번호 회원가입 및 로그인
  • 이름, 희망 직무, 한 줄 소개 등 개인 프로필 작성
  • 프로젝트 개요, 담당 역할, 문제, 해결 과정, 성과 입력
  • 프로젝트 관련 텍스트 링크 등록
  • 완성한 프로젝트의 공개·비공개 설정
  • 고유 주소를 가진 웹 포트폴리오 발행
  • 로그인하지 않은 방문자의 공개 포트폴리오 열람
  • 사용자별 데이터를 PostgreSQL에 저장

개발 및 확인

Next.js + PostgreSQL + Vercel을 기반으로 개발하고, Neon 데이터베이스를 연결해 실제 서비스로 배포했습니다.

회원가입 → 프로필 작성 → 프로젝트 등록 → 공개 설정 → 포트폴리오 발행 → 고유 주소 접속

위 흐름을 직접 실행해 데이터 저장과 공개 페이지 노출 여부를 확인했습니다.
