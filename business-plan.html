02 PROBLEM

어떤 불편

  • 결과물 중심 포트폴리오만으로는 실제 역할과 기여도를 전달하기 어렵다.
  • 문제 상황에서 내린 판단과 트러블슈팅 과정이 충분히 드러나지 않는다.
  • 문서·이미지·링크·GitHub 자료를 하나의 포트폴리오로 통합하는 데 시간이 소요된다.

04 VALUE

우리가 바꿀 점

  • 담당 역할 → 문제 상황 → 해결 과정 → 구체적 성과 순서의 작성 구조를 제공한다.
  • 프로젝트 자료와 링크를 한곳에서 등록하고 공개 여부를 관리한다.
  • 완성된 프로젝트를 반응형 단일 페이지에 배치해 고유 URL로 발행한다.
핵심 가치

“무엇을 만들었는가”에서 “어떤 문제를 어떻게 해결했는가”로 포트폴리오의 평가 단위를 전환

제품 성공 지표
  • 가입 → 첫 프로젝트 완성률
  • 첫 프로젝트 → 포트폴리오 발행률
  • 작성 시작 → 공개 URL 생성 시간
  • 발행 후 공유·재방문·수정률
05 CHANNEL

알리는 길

발행된 고유 URL을 이력서·지원서 등 채용 과정에서 공유해 채용 담당자가 로그인 없이 확인하도록 한다.

초기 고객 확보
  • 대학일자리플러스센터·취업지원 부서와 포트폴리오 워크숍 제휴
  • 부트캠프·청년 일경험·프로젝트 교육 수료자의 결과물 발행 도구로 공급
  • 직군별 취업 커뮤니티에 실제 포트폴리오 개선 사례를 콘텐츠로 배포
  • 무료 포트폴리오 하단 Folioframe 표기로 자연 유입 연결

고용24는 대학 취업지원 프로그램에 포트폴리오 경진대회·구성 지원을 포함함 · 고용24

07 ASSUMPTION

위험한 가정

01취업 준비생은 구조화된 질문이 있으면 프로젝트 서사를 끝까지 작성한다.
02작성·통합·발행 과정이 기존 문서 조합 방식보다 빠르다.
03채용 담당자는 고유 URL에서 지원자의 역할과 기여도를 더 쉽게 파악한다.
04일반 사이트 제작 도구보다 취업 특화 구조가 선택 이유가 된다.
05무료 발행 이후 브랜딩 제거·분석·PDF·도메인 기능에 지불 의사가 있다.
06대학·교육기관이 수료자의 결과물 관리 도구를 구매한다.
